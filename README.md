# The Plant

Portfolio of Allonzo Pensabene, building automation and energy engineer.

A cutaway building at night: each room is a project. Walk the engineer in to commission it.
A 2D list of the same projects is one click away (`?view=list`).

Vite, React, TypeScript, React Three Fiber, drei, zustand, GSAP, Motion, Tailwind.

```bash
npm install
npm run dev
```
